# Metric Audit Workspace

This directory is organized into:

- `vulnerabilities/` - individual vulnerability reports.
- `solidity-tests/` - archived copies of audit PoCs, Foundry fuzz tests, and Echidna harnesses, grouped by source project.
- `submission-triage.md` - submission ranking and validation status.
- `to-check.md` - unresolved leads.
- `stale-price-review.md` - focused oracle review notes.
- `no_complexity_contracts.md` - contract complexity notes.
- `comenzi.md` - useful commands.

The Solidity files remain in their original project test directories as well. Run them from `metric-core`, `metric-periphery`, or `smart-contracts-poc`; the copies under `solidity-tests/` are for centralized review and preservation.
